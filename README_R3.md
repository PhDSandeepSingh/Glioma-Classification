# Glioma-Classification — Canonical Analysis & Reproducibility Guide

**Manuscript:** *Impact of diagnostic label–IDH discordance and WHO 2021 criteria on machine-learning glioma grading from somatic mutations* (*Scientific Reports*)

This directory contains the complete, self-contained canonical analysis pipeline, data provenance records, and patient-level WHO 2021 label release (`v1.0`).

**Research use only.** Neither the trained classifiers nor the reconstructed WHO 2021 labels are intended for clinical diagnosis or patient management.

## Reproduce

**Requirements**
- **Python 3.13.x** (canonical run: CPython `3.13.16` on Linux `x86_64`).
- **Package versions** matching `Results/Models/reproducibility_report.json`: `scikit-learn==1.6.1`, `xgboost==3.4.1`, `shap==0.54.1`, `imbalanced-learn==0.14.2`, `numpy==2.4.6`, `pandas==2.2.3`, `scipy==1.16.3`, `statsmodels==0.15.0`, `matplotlib==3.10.0`, `seaborn==0.13.2`.

**Install**
```bash
python3.13 -m venv .venv && . .venv/bin/activate
pip install -r environment/requirements-lock.txt   # exact environment, or: pip install -r requirements.txt
# conda alternative:  conda env create -f environment/environment.yml && conda activate glioma-r3
```

**Run**
```bash
python build_notebook.py      # optional: regenerate the notebook from source
python run_nb.py              # executes the notebook headlessly and saves all outputs
```

**From-scratch run**
Delete `Results/` first if you wish to rebuild all cached model artifacts from scratch. Cached steps are keyed on the input data SHA-256 hash, the run tag, and a hash of the generating function code.

**Verification checks**
- Compare the regenerated `Results/ManuscriptNumbers.csv` and `Results/Tables/*.csv` with the released copies.
- Verify that `Results/Models/test_set_predictions.csv` and `Results/Models/locks_before_test.json` match the recorded artifacts.
- Fitted model pickles are tied to the pinned Python, `scikit-learn`, and `xgboost` versions and should not be loaded under mismatched package versions.

## Key Pipeline Features
1. **Pre-locked development pipeline:** Imbalance handling (`Class-weight (balanced)`, spread `0.0007`), primary estimator (`XGBoost`, mean-of-fold AUC `0.915`, pooled OOF AUC `0.912`), cross-fitted Platt calibration, Youden threshold (`0.351`), and the 4-feature panel (`IDH1, Age_at_diagnosis, IDH2, TP53`) are selected strictly within the 671-patient development partition (fixed a priori 80/20 stratified development/test split, seed 42) and locked before scoring the 168-patient test partition.
2. **Leakage-free nested validation & joint selection:** Includes 10×5-fold repeated nested cross-validation (`0.913 ± 0.005` pooled OOF AUC), fully nested inner-loop joint selection across 3 valid imbalance strategies × 4 model families (`tools/run_fully_nested_joint.py`: mean-of-fold AUC `0.908 ± 0.023`, pooled OOF AUC `0.905`), and fully nested LOFO and reduced-panel ablations with paired DeLong tests and Holm correction.
3. **Zero-parameter IDH rule comparators & concordance stratification:** Benchmarks multivariable classifiers against zero-parameter *IDH1* and *IDH1/2* rules using exact McNemar tests, Newcombe Method 10 paired score confidence intervals, and decision curve analysis, stratifying errors by label–IDH concordance.
4. **Post hoc WHO 2021 molecular reconstruction & 64-column label release:** Links all 839 patients to published TCGA 1p/19q, `+7/-10`, *TERT* promoter, *EGFR*/*CDKN2A/B* GISTIC 2.0, and H3 hotspot annotations across 10 sensitivity variants, cIMPACT-NOW Update 11 criteria, and external concordance with de Mendonça et al. (2025).
